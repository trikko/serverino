    Struct Https

    A set of TLS certificates, to be attached to a listener.

    struct Https;

    The set is accumulable and can be built from a range, so certificates don't need to be known at compile time: they can come from a directory, from the command line or from a configuration file. 

    // A single certificate, known upfront
config.addListener("0.0.0.0", 443, Https("fullchain.pem", "privkey.pem"));

// Every certificate found in a directory
auto certs = Https();
foreach(f; dirEntries(dir, "*.crt", SpanMode.shallow))
   certs.add(f.name, f.name.setExtension(".key"));

config.addListener("0.0.0.0", 443, certs);

    The first certificate of the set is the default one, the others are picked using SNI.

    this (paths) Build a set from an even number of paths, in cert/key order.
    this (certificates) Build a set from a range of Https.Certificate, or of anything indexable with two elements (string[2], Tuple!(string, string), ...)

    Methods

    NameDescription
    add (certPath, keyPath) Add a certificate to the set. Chainable.
    add (paths) Add an even number of paths, in cert/key order. Chainable.
    certificates () The certificates, in insertion order. The first one is the default one.
    empty () Is this set empty?
    length () How many certificates are in this set?
    opOpAssign (certificate) Append a certificate, or another set of certificates.
