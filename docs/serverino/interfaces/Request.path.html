    Function Request.path

    The path requested by user.

    const(string) path() nothrow @property @nogc @safe const;

    It is already normalized: . and .. segments are collapsed away, so it can't escape upwards. It is **not** percent-decoded, though: don't decode it yourself, or a request like /%2e%2e/%2e%2e/etc/passwd turns back into a traversal *after* the normalization that would have stopped it. If you need a decoded path, normalize (or confine) it again afterwards.
