Examples

Try it here, then read the code

The demos below are endpoints of this website: breaking one of its worker processes, watching it measure its own memory, talking to it over a WebSocket. The code next to each one is cut out of the file that serves it, so it cannot say something different from what runs.

They are on a leash, as a public site should be: 600 requests every ten seconds per visitor, six WebSockets a minute, 24 open at once site-wide, and every connection closed after a few minutes. That leash is one short module, and it is worth a read if you are putting something of your own on the internet.
